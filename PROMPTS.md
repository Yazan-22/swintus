## 1. AI Tools Used

I mainly used **ChatGPT** while developing my Swintus card game.

It helped me plan the project, write some Python code, fix errors, create tests, and improve the GUI.

## 2. Successful Prompts

**Prompt 1:** "Help me organize my Swintus project into different Python files."

This helped me separate the code into classes like `Card`, `Deck`, `Player`, and `Game`, making the project easier to understand.

**Prompt 2:** "Help me create a simple GUI for my Swintus game using Tkinter."

This was useful because it gave me a starting point for the interface, including buttons for playing and drawing cards.

**Prompt 3:** "Help me write tests using pytest."

This helped me check whether the game logic was working correctly.

## 3. Failed Prompts

**Prompt 1:** "Fix my code."

This didn't always work because I didn't provide enough information. I learned to include the error message and the relevant code to get better answers.

**Prompt 2:** "Make the GUI better."

The result wasn't always what I expected because the request was too general. Later, I explained exactly what I wanted to change, such as the buttons, colors, and labels.

## 4. Conclusions

During this project, I learned that AI can be very helpful, especially for writing code, finding errors, and explaining difficult parts.

However, AI doesn't always give the correct solution. Sometimes I had to change the code myself or ask more specific questions.

I also learned that **the more specific the prompt is, the better the result usually is.**

## 5. AI Usage Volume

I estimate that around **50–60% of the code was written with AI assistance**.

The rest involved manual changes, testing, debugging, and connecting different parts of the project.

Overall, ChatGPT helped me develop the game faster, but I still needed to understand the code and test everything myself.
